# Посмотри в окно

Учебный проект Яндекс Практикума. Страница позволяет искать видеозаписи по городу и времени суток.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер в корне проекта.

## Технологии

HTML, CSS и JavaScript.
